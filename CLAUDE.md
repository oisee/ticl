## Overview

**ticl** (Tabular In-Context Learning) is a framework for training and deploying in-context learning models for tabular data classification. It includes three main models:

- **MotherNet**: A hypernetwork foundational model that generates small neural networks for tabular classification
- **GAMformer**: An interpretable additive model using in-context learning
- **TabFlex**: An extension of TabPFN using linear attention to overcome scaling limitations

All models are based on TabPFN architecture from the Freiburg AutoML group.

## Common Commands

### Training Models

Train any model using `fit_model.py` as the main entry point:

```bash
# Train MotherNet (paper configuration)
python ticl/fit_model.py mothernet -L 2

# Train MotherNet with specific GPU
python ticl/fit_model.py mothernet -g 0

# Train GAMformer
python ticl/fit_model.py gamformer

# Train TabFlex
python ticl/fit_model.py tabflex

# See all options for a model type
python ticl/fit_model.py mothernet -h
python ticl/fit_model.py -h  # General options
```

**Training features:**
- MLFlow tracking (if `MLFLOW_HOSTNAME` environment variable is set)
- Multi-GPU training supported via `torchrun`
- Checkpoint saving/resuming via `--base-path` and `--continue-run`
- Config-driven architecture (configs in `ticl/configs/`)

### Model Inference

All models have sklearn-compatible interfaces:

```python
from ticl.prediction import MotherNetClassifier
from sklearn.model_selection import train_test_split

# MotherNet
clf = MotherNetClassifier(device='cpu')
clf.fit(X_train, y_train)
y_pred = clf.predict(X_test)

# TabFlex
from ticl.prediction.tabflex import TabFlex
tabflex = TabFlex()
tabflex.fit(X_train, y_train)
y_pred = tabflex.predict(X_test)
```

### Key Design Patterns

1. **Encoder-Backbone-Decoder Architecture**: All models follow this three-part structure
   - Encoder: Converts tabular input to embeddings (Linear, OneHotAndLinear, BinEmbedding)
   - Backbone: Transformer layers (standard attention, bi-attention, or linear attention)
   - Decoder: Converts representations to predictions (MLPModelDecoder, AdditiveModelDecoder)

2. **Prior-Based Training**: Models train on synthetic data generated by "priors"
   - `ClassificationAdapterPrior` is the main wrapper
   - Supports MLPPrior, GPPrior, BooleanConjunctionPrior, etc.
   - `PriorDataLoader` in `dataloader.py` generates batches on-the-fly

3. **Config-Driven**: Architecture controlled by YAML configs in `ticl/configs/`
   - Default configs in `model_configs.py` via `get_model_default_config()`
   - CLI args override config values
   - Use `config_utils.py` for merging configs

4. **Sklearn Compatibility**: All prediction interfaces inherit from `BaseEstimator`
   - `fit(X, y)` and `predict(X)` methods
   - Automatic preprocessing (StandardScaler, normalization)
   - Model weights downloaded automatically from blob storage

5. **Batch-first Convention**:
   - MotherNet uses `batch_first=False` (legacy from TabPFN)
   - Newer models (GAMformer, TabFlex) use `batch_first=True`

### Model-Specific Details

**MotherNet** (`ticl/models/mothernet.py:122`):
- Hypernetwork that predicts weights/biases for a small child neural network
- Uses `TransformerEncoder` backbone
- `MLPModelDecoder` outputs network parameters
- Inference: forward pass through predicted network

**GAMformer** (`ticl/models/gamformer.py:201`):
- Outputs interpretable additive model: y = β₀ + Σᵢ fᵢ(xᵢ)
- Uses `BiAttentionEncoderLayer` (attends features to samples and vice versa)
- `FactorizedAdditiveModelDecoder` or `AdditiveModelDecoder`
- Supports binning and shape function visualization

**TabFlex** (`ticl/models/tabflex.py:99`):
- Linear attention for scalability (millions of samples, thousands of features)
- Uses `get_linear_attention_layers()` from `linear_attention.py`
- ~2x speedup over TabPFN, handles much larger datasets
- Compatible with TabZilla benchmark framework

### Training Pipeline Flow

1. **CLI Parsing** (`cli_parsing.py`): Parse arguments via `make_model_level_argparser()`
2. **Config Loading** (`model_configs.py`): Load defaults with `get_model_default_config()`
3. **Model Building** (`model_builder.py`): Instantiate via `get_model()`
4. **Data Generation** (`dataloader.py`): Create `PriorDataLoader` with synthetic prior
5. **Training Loop** (`train.py`): Iterate epochs with `train_epoch()`
6. **Checkpointing**: Save model state and config to `--base-path`

### Prediction Pipeline Flow

1. **Model Loading**: Fetch from blob storage or local path
2. **Preprocessing**: Apply StandardScaler, normalize features
3. **Forward Pass**: Run model inference
4. **Postprocessing**: Extract predictions (from linear model or MLP)

## Notes

- **MLFlow Integration**: Set `MLFLOW_HOSTNAME` environment variable to enable experiment tracking
- **Model Checkpoints**: Downloaded automatically from Microsoft blob storage on first use
- **Multi-GPU Training**: Use `torchrun` for data-parallel training across multiple GPUs
- **Preprocessing**: MotherNet benefits from one-hot encoding during inference (improves accuracy)
- **Feature Scaling**: Handled internally by all models
- **Testing**: Run `pytest ticl/tests/` to verify installation and functionality
